# Levis AI 功能指南

Levis 提供续写、语法检查，以及围绕文档的对话和修改。本指南介绍连接服务、使用功能，以及用项目文件夹和 Agent 工作区把 Agent 调成你自己的写作助手。

## 连接服务

1. 打开 **设置 > AI 服务**，在**服务商**中选择要使用的服务。
2. 展开**登录与凭据**，按该服务支持的方式登录账户或填写 API Key。
3. 使用**自定义接口**（任何兼容 OpenAI 的服务：本地模型、中转等）时，填写接口地址、所需的密钥和模型名称，再保存配置。
4. 在**续写与语法**中选择写作模型。对话模型在 **设置 > Agent** 中选择。

登录会在浏览器中完成。是否支持图片、联网搜索和文档修改，取决于所选服务与模型。

内置的模型列表只包含各服务商的默认模型（Anthropic：Agent 用 Claude Sonnet 5.5，续写和语法检查用 Claude Haiku 5.5）。点模型选择框旁的 **获取模型列表**，即可载入该服务商当前的全部模型并从中选择。

以下快捷键按 macOS 标注；Windows 和 Linux 将 Cmd 换成 Ctrl、Option 换成 Alt。修改过快捷键时，以 **设置 > 快捷键** 中的配置为准。

## AI 功能

### 1. 续写（补全）

输入时自动在光标处给出灰色的续写建议，按 <kbd>Tab</kbd> 采纳；按 <kbd>Cmd</kbd>+<kbd>→</kbd> 只采纳下一个词，其余部分继续保留。<kbd>Esc</kbd> 关闭建议。没有最小字数限制，文档第一句话就能触发。

用 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> 或右键菜单主动请求续写时（光标需在段落末尾），会得到更长的续写，并最多给出三个候选——用 <kbd>Option</kbd>+<kbd>[</kbd> / <kbd>Option</kbd>+<kbd>]</kbd> 切换。

在 **设置 > AI 服务 > 续写与语法** 里可以调整**续写语气**（跟随文档 / 正式 / 轻松 / 学术 / 简洁）。如果文档所在的项目有文风档案或资料库（见下文），续写也会遵循它们。

### 2. 语法检查

对可能有问题的文字加下划线。鼠标悬停或把光标移进去即可查看说明；点**应用**（或光标在其上时按 <kbd>Option</kbd>+<kbd>Enter</kbd>）采用修改，点**忽略**则不再提示。快捷键 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> 立即检查当前段落。

### 3. AI 面板

完整对话位于编辑器右侧的面板中。点窗口标题栏右端的对话按钮，或按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> 打开或关闭。

- **每个文档一个对话**：每个标签页有自己的对话，切换标签页时面板也随之切换。面板顶部的**新对话**重新开始（还有未处理的修改时会先询问）。
- **模式**：输入框提供**询问**、**编辑**、**计划**三种模式。面板的初始模式在 **设置 > Agent > 默认模式** 中设置。
- **@ 引用**：在输入框中输入 `@`，即可从项目文件夹里选一个文本文件附到消息中。
- **附加文件**：点输入框左侧的 **+** 可以附上 PDF、Word、PowerPoint、表格、图片或纯文本。除图片外都会在本地抽成文字再随消息发出；图片则作为真正的图像发给支持视觉的服务（不支持的会直接提示，而不是悄悄丢掉）。文件很长时只会发送一部分，附件标签上会注明「已截断」。
- **联网搜索**：在 **设置 > Agent** 中开启后（仅限支持的服务），Agent 需要时可以自己搜索网页。
- **历史记录**：侧栏的「对话」标签页会保存过去的对话，点击其中一条即可在当前编辑器里重新打开并继续。
- **出错时**：请求失败时，对话会先说明是哪类问题、该怎么办（检查密钥、稍后再试、换一个模型），再附上服务商的原始信息。

面板顶部的**在独立窗口中打开**会把对话移到单独的窗口，适合放在第二块屏幕上。这个窗口会跟着你走：切换标签页或窗口，它的文档、标题和选区都会跟着变；提出的修改始终落在你当时正在编辑的那个文件上。每个编辑器窗口最多只有一个独立窗口；右上角的 **📌** 可以让它一直显示在编辑器上方。

### 4. 快速提问

按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>（或右键 > 询问 AI…）在当前段落下方打开一个小对话条。它嵌在文档中，会把下方内容往下推，不会遮住正文。如果打开前选中了文字，会附上选中内容。快速提问默认使用**编辑**模式，因为它通常是针对某段文字发起修改（「缩短这段」）；需要时可在模式选择中一键切回询问。

- **再按一次快捷键**：对话条已打开时按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> 会把光标移到输入框；在输入框中再按一次则关闭。在对话条任意位置按 <kbd>Esc</kbd> 也会关闭，光标回到正文。还有未处理的修改时，关闭或新建对话会先询问。
- 快速提问有自己的简短对话，和面板里的对话分开，也不写入对话历史；面板开着时也能弹出。点右上角的**转到大对话**，这段对话会交给 AI 面板继续，并保存到历史。打开 **设置 > Agent > 高级设置 > 在独立窗口中打开完整对话** 后，则改为在独立窗口中打开。

### 5. 文档内的修改

对话不会直接改动文档。当你让支持工具调用的服务修改文档时，每处修改都以提议的形式呈现在原位：删除的文字加删除线，新增的文字以绿色显示。采纳前文档不会有任何变化，<kbd>Cmd</kbd>+<kbd>Z</kbd> 可以一步撤销已采纳的修改。

- **采纳 / 拒绝**：可以用修改旁的浮动条、面板中该提议的卡片，或键盘——<kbd>Cmd</kbd>+<kbd>Return</kbd> 采纳，光标在修改上时 <kbd>Cmd</kbd>+<kbd>Delete</kbd> 拒绝。一条回复里有多个提议时会同时预览，可用 ‹› 切换，也可以全部采纳/全部拒绝。
- **修改理由**：每张提议卡片都会说明 Agent 为什么这样改。
- **只采纳部分句子**：一个提议改写了多句话时，卡片上会出现「N 处句子改动 · 逐句选择」——勾选想要的句子，再点**接受所选**。
- **在光标处插入**：没有选中文字时，Agent 知道光标的位置，「在这里写一段过渡」会正好插在光标处。
- **批注而非修改**：请 Agent 审阅（「这里哪里写得弱？」）时，它会把批注钉在对应段落上，而不改动原文。每张批注卡片都有**在文档中定位**，点击会选中它所针对的段落。

## 项目文件夹

文档保存后，**它所在的文件夹就是项目**。Agent 可以列出、阅读和搜索其中的文本文件（Markdown、纯文本等格式），用来查找某个角色之前的戏份、某个术语，或你的笔记。隐藏文件和文件夹、构建与依赖目录（如 `node_modules`），以及超过 100 KB 的文件都会被跳过。未保存的草稿没有项目；范围太大的文件夹（主目录或整个磁盘）会被拒绝。

AI 面板顶部下方的项目栏显示当前项目。它的菜单可以**选择项目文件夹…**（参考资料和草稿不在一起时）、**改用文档所在文件夹**，或**在文件管理器中显示**。同样的设置也在 **设置 > Agent > 工作区文件夹**。Agent 读取的一切都必须在项目之内：`..`、绝对路径和指向外部的软链接都会被拒绝。

项目的 `.levis/` 文件夹里还有两样写作辅助：

```
我的小说/
├── 第一章.md
└── .levis/
    ├── style.md          ← 你的文风档案
    └── library/
        ├── 林晚.md        ← 每个人物、地点或术语一个条目
        └── 港城.md
```

### style.md — 你的文风

描述你怎么写：语气、句子节奏、用词、绝不会做的事。Agent 和续写在项目内的所有文档中都会遵循它。可以在项目菜单中**新建文风档案**，也可以用**从样本学习我的文风…**：选几篇你自己写的文件，AI 会据此起草档案，并在新标签页中打开供你检查修改（旧档案会保留为 `style.previous.md`）。

### library/ — 需要保持一致的事实

每个人物、地点或术语一个 Markdown 文件（项目菜单中的**新建资料条目…**会创建一个）：

```markdown
---
name: 林晚
aliases: [晚晚, 林老师]
include: detected
---

女主角，32 岁，在一所中学教语文……
```

条目不需要你手动附加。`include: detected`（默认值）的条目，只要它的名字或别名出现在你的消息、选中的文字或光标附近的文字中，就会自动交给 AI；`always` 每次请求都会带上，`never` 则永远不带。资料库再大，没有用到的条目也不会产生开销。

## Agent 工作区

指令和技能放在同一个 `.levis/` 文件夹里：

```
我的小说/
├── 第一章.md          ← 正在编辑的文档
└── .levis/
    ├── agent.md       ← 常驻指令：文风、术语表、项目背景
    └── skills/
        ├── polish.md  ← 技能：一个文件一个技能
        └── outline.md
```

另外还有一个**全局层**，对所有文档生效（**设置 > Agent > 打开全局文件夹**），结构相同。工作区里同名的技能会覆盖全局的。

### agent.md — 常驻指令

`agent.md` 里的内容每次对话都会告诉 Agent。适合放：对回复的要求、这个项目是什么、Agent 始终要遵守的规则。

### skills/ — 技能

一个技能 = 一个 Markdown 文件：开头是 YAML 说明，正文是完整指令。

```markdown
---
name: polish
description: 润色选中的段落，保持原意，收紧句子
---

对给出的文字逐句润色：删掉冗余的词，把长句拆短，
保持原本的意思和语气不变。只输出润色后的文字。
```

技能有两种触发方式：

1. **手动**：在对话框输入 `/`，从菜单里选（或直接输 `/polish 再帮我看看这段`）。
2. **自动**（仅支持工具调用的服务）：Agent 知道每个技能的名字和描述，当你的请求和某个技能的描述匹配时，它会自己加载并遵循完整指令。

> [!NOTE]
> `.levis/` 里的文件改完无需重启——Agent 的下一次请求就会用新的内容（续写会在几秒内生效）。

## 隐私说明

文档内容、附加和 @ 引用的文件、工作区指令、文风档案、相关的资料条目，以及 Agent 读取的项目文件，会随请求发送给你所选的服务。联网搜索由该服务在服务端执行。不需要时在设置里关掉对应功能即可。
