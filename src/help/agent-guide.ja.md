# Levis AI機能ガイド

Levisには執筆専用のAI「Levis AI」が内蔵されています。続き書き、文法チェック、そして文書を読んで書き直す対話です。このガイドでは、サービスの接続方法、AI機能の使い方、そしてプロジェクトフォルダー、文体プロファイル、ライブラリ、執筆の指示とスキルを使ってLevis AIを自分だけの執筆アシスタントにカスタマイズする方法を説明します。

## サービスの接続

1. **設定 > Levis AI** を開き、**接続** の **プロバイダー** で使うサービスを選びます。
2. **ログインと認証** を展開し、そのサービスが対応する方法でアカウントにサインインするか、APIキーを入力します。
3. **カスタムエンドポイント**(OpenAI互換の任意のサーバー:ローカルモデル、中継サービスなど)を使う場合は、ベースURL、必要ならキー、モデル名を入力して保存します。
4. 執筆モデルは **執筆アシスト** で、チャットモデルは **Levis AI チャット** で選びます。

サインインはブラウザで行います。画像、ウェブ検索、文書の編集が使えるかどうかは、選んだサービスとモデルによります。

内蔵のモデル一覧には各プロバイダーの既定モデルだけが入っています(Anthropicの場合、チャットはClaude Sonnet 5.5、補完と文法チェックはClaude Haiku 5.5)。**接続** のモデル一覧の行にある **モデル一覧を取得** を押すと、そのプロバイダーの現在のモデル一覧を読み込んで、その中から選べます。

以下のショートカットはmacOSの表記です。WindowsとLinuxではCmdをCtrl、OptionをAltに読み替えてください。ショートカットを変更した場合は、**設定 > ショートカット** の設定が優先されます。

## AI機能

### 1. 続き書き(補完)

入力中にカーソル位置へ自動的にグレーの続き書き候補が表示され、<kbd>Tab</kbd>で採用します。<kbd>Cmd</kbd>+<kbd>→</kbd> なら次の1語だけを採用し、残りは候補のまま残ります。<kbd>Esc</kbd>で候補を消します。最小文字数の制限はなく、文書の最初の一文からでも動作します。

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> または右クリックメニューで明示的に呼び出すと(カーソルは段落の末尾に置きます)、より長い続き書きが最大3つの候補とともに表示されます —— <kbd>Option</kbd>+<kbd>[</kbd> / <kbd>Option</kbd>+<kbd>]</kbd> で切り替えます。

**設定 > Levis AI > 執筆アシスト** で**補完のトーン**（文書に合わせる / フォーマル / カジュアル / 学術的 / 簡潔）を調整できます。文書が文体プロファイルやライブラリを持つプロジェクトに属している場合(後述の「Levis AIを自分仕様にする」を参照)、補完もそれに従います。

### 2. 文法チェック

問題の可能性がある箇所に下線が引かれます。ホバーするか、カーソルをその中に移すと説明が表示されます。**適用**(またはカーソルがその上にあるときに <kbd>Option</kbd>+<kbd>Enter</kbd>)で修正を取り込み、**無視**で表示を消します。ショートカット <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> で現在の段落を即座にチェックします。

### 3. AIパネル

会話全体はエディタ右側のパネルにあります。ウィンドウバー右端のチャットボタン、または <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> で開閉します。

- **文書ごとに1つの会話**:タブごとに会話があり、タブを切り替えるとパネルも切り替わります。パネルのヘッダーの **新しい会話** でやり直せます(未処理の編集があるときは先に確認します)。
- **モード**:入力欄には **質問**、**編集**、**計画** の3つのモードがあります。パネルの初期モードは **設定 > Levis AI > Levis AI チャット > デフォルトモード** で設定します。
- **@メンション**:入力欄で `@` と入力すると、プロジェクトフォルダ内のテキストファイルを選んでメッセージに添付できます。
- **ファイルの添付**:入力欄左側の **+** をクリックすると、PDF、Word、PowerPoint、表計算、画像、テキストファイルをそのメッセージに添付できます。画像以外はローカルでテキストに変換されてメッセージに埋め込まれ、画像は視覚に対応したプロバイダーへ本物の画像として送られます(非対応のプロバイダーは黙って捨てるのではなく、その場で知らせます)。長いファイルは一部のみが送られ、その場合は添付タグに「（一部のみ）」と表示されます。
- **ウェブ検索**:**設定 > Levis AI > Levis AI チャット** で有効にすると(対応しているプロバイダーのみ)、必要に応じてLevis AIが自らウェブを検索します。
- **履歴**：サイドバーの「チャット」タブに過去の会話が保存されます。クリックすると現在のエディタで開き直して続けられます。
- **エラー時**:リクエストが失敗すると、プロバイダー自身のメッセージの上に、どんな種類の問題で何をすればよいか(キーを確認する、少し待つ、別のモデルを選ぶ)が表示されます。

パネルのヘッダーの **別ウィンドウで開く** で、会話を独立したウィンドウに移せます。2台目のモニターで便利です。このウィンドウはあなたに追従します:タブやウィンドウを切り替えると、文書・タイトル・選択範囲がそれに追従し、提案される編集はその時点で編集しているファイルに落ちます。独立ウィンドウはエディタウィンドウごとに1つだけです。ヘッダーの **📌** でエディタより前面に固定できます。

### 4. クイック質問

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>(または右クリック > AIに聞く…)で、いまいる段落のすぐ下に小さな対話バーを開きます。バーは文書の中に置かれ、本文を覆わずに下の内容を押し下げます。開く前にテキストを選択していれば、その選択範囲も渡されます。クイック質問は **編集** モードで開きます。たいていは書き換えたい箇所で開くからです(「ここを短く」)。質問モードにはモード選択からワンクリックで切り替えられます。

- **もう一度ショートカット**:バーが開いているときに <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> を押すと入力欄にカーソルが移り、入力欄でもう一度押すとバーを閉じます。バー内のどこでも <kbd>Esc</kbd> で閉じられ、カーソルは本文に戻ります。未処理の編集があるときは、閉じる前(または新しい会話を始める前)に確認します。
- クイック質問はパネルとは別の短い会話を持ち、履歴には保存されません。パネルを開いていても使えます。右上の **会話パネルで続ける** で、このやり取りを AI パネルに引き継ぎ、そこで続けて履歴に保存できます。**設定 > Levis AI > 詳細設定 > 会話全体を別ウィンドウで開く** を有効にすると、代わりに別ウィンドウで開きます。

### 5. 文書内での編集

対話が文書を直接書き換えることはありません。ツール呼び出しに対応したプロバイダーに文書の変更を依頼すると、変更はそれぞれ提案として変更箇所にその場で表示されます:削除されるテキストには取り消し線、追加されるテキストは緑色で表示されます。承認するまで文書には一切変更が加わらず、<kbd>Cmd</kbd>+<kbd>Z</kbd>で承認済みの変更を一度で取り消せます。

- **承認 / 却下**:編集のそばのフローティングバー、パネル内の提案カード、またはキーボードで操作します —— <kbd>Cmd</kbd>+<kbd>Return</kbd> で承認、カーソルが編集の上にあるときに <kbd>Cmd</kbd>+<kbd>Delete</kbd> で却下。1回の返信に複数の提案がある場合は同時にプレビューされ、‹›で切り替え、すべて承認/すべて却下もできます。
- **理由**:提案カードには、Levis AIがその変更をした理由が表示されます。
- **一部の文だけ**:提案が複数の文を書き換える場合、カードに「N か所の文の変更 · 選んで適用」が表示されます —— 欲しい文にチェックを入れて **選択した変更を適用** を押します。
- **カーソル位置に**:何も選択していないとき、Levis AIはカーソルの位置を把握しているので、「ここにつなぎの文を」と頼めばちょうどそこに挿入されます。
- **編集ではなくコメント**:レビューを頼むと(「ここの弱いところは?」)、Levis AIは本文を変えずに該当箇所へコメントを付けます。コメントカードの **文書内で表示** を押すと、その箇所が選択されます。

## Levis AIを自分仕様にする

Levis AIがあなたとあなたの作品について知る手がかりは、隠れた設定ではなく、いくつかの普通のMarkdownファイルです。それぞれの役割は1つだけです：

| 概念 | 何か | 置き場所 |
| --- | --- | --- |
| **プロジェクトフォルダー** | Levis AIが作業し、読み取れるフォルダー | 文書のフォルダー、または自分で選んだフォルダー |
| **文体プロファイル** | あなたの書き方 | `.levis/style.md` |
| **ライブラリ** | 人物・場所・用語の設定 | `.levis/library/` |
| **執筆の指示** | 毎回の会話で守らせる常設のルール | `agent.md`（グローバルとプロジェクトごと） |
| **スキル** | `/名前` で呼び出す再利用できる指示 | `skills/`（グローバルとプロジェクトごと） |
| **グローバル設定フォルダー** | すべての文書に適用されるもの | アプリの設定フォルダー |

以下の「会話」は、AIパネルとクイック質問のことです。プロジェクト全体はおおよそ次のようになります：

```
私の小説/                ← プロジェクトフォルダー
├── 第一章.md            ← 編集中の文書
├── メモ/
│   └── 年表.md          ← Levis AIが参照できる資料
└── .levis/              ← プロジェクト自身の設定
    ├── style.md         ← 文体プロファイル
    ├── agent.md         ← このプロジェクトの執筆の指示
    ├── library/
    │   ├── 林晩.md       ← 人物・場所・用語ごとに1項目
    │   └── 港町.md
    └── skills/
        └── polish.md    ← 1ファイル1スキル
```

`.levis/` とその中のファイルは、プロジェクトメニューから初めて使うときに自動で作られます。手で追加するのはプロジェクトのスキルだけです。どのファイルでも、`<!-- -->` のコメント内に書いたことは自分用のメモで、送信されることはありません。

### プロジェクトフォルダー

**プロジェクトフォルダーは、Levis AIが作業するフォルダーです。** 既定では編集中の文書があるフォルダーで、文書を保存すると、そのフォルダーがプロジェクトフォルダーになります。

- Levis AIはその中のテキストファイル（Markdown、テキストなど）を一覧・読み込み・検索でき、登場人物の以前の場面、用語、メモなどを探せます。隠しファイルと隠しフォルダー、ビルドや依存関係のフォルダー（`node_modules` など）、100 KBを超えるファイルは対象外です。
- 対話の入力欄で `@` と入力すると、その中のファイルをメッセージに添付できます。
- その `.levis/` フォルダーに、このプロジェクトの文体プロファイル、ライブラリ、執筆の指示、スキルが置かれます。

AIパネルのヘッダーの下にあるバーにプロジェクトフォルダーの名前が表示され、クリックすると**プロジェクトメニュー**が開きます。参考資料が草稿と別の場所にあるときは、そこから **プロジェクトフォルダーを選択…** を使います（**設定 > Levis AI > プロジェクトフォルダー** でも選べます）。選んだフォルダーは、**文書のフォルダーを使う** で戻すまで、保存していない草稿も含めてすべての文書で使われます。

> [!TIP]
> 草稿は `論文/草稿/`、インタビューのメモは `論文/資料/` にある？ `論文/` をプロジェクトフォルダーに選べば、`草稿/第二章.md` を書きながら、Levis AIが `資料/インタビュー.md` を読めます。

Levis AIが読むものはすべてプロジェクトフォルダー内に限られ、`..`、絶対パス、外部を指すリンクはいずれも拒否されます。フォルダーを選んでいない場合、保存していない草稿にはプロジェクトフォルダーがありません。範囲が広すぎるフォルダー（ホームフォルダーやドライブ全体）も拒否されます。

### 文体プロファイル ——「文体を学習」

**文体プロファイルは、あなたの書き方の説明です。** 続き書きや編集があなたらしく読めるように、語調、文のリズム、言葉選び、句読点、決して使わない書き方を書きます。プロジェクト内のすべての文書で、Levis AIは会話のときに、補完は入力中に、これに従います。実体は `.levis/style.md` というファイルです。

作り方は2つあり、どちらもプロジェクトメニューにあります：

- **サンプルから文体を学習…** —— 自分で書いたファイルをいくつか（8つまで）選びます。Levis AIがそれを読んでプロファイルを下書きし（語調、文とリズム、言葉選び、句読点と書式、構成、使わない書き方、例として短い引用をいくつか）、新しいタブで開きます。読んで、違うところを直し、足りないところを書き足してください。もうあなたのものです。もう一度学習すると、以前のプロファイルは `style.previous.md` として残ります。
- **文体プロファイルを作成** —— 空の見出しから自分で書きます。

プロファイルができると、フォルダー名の横に**文体**チップが表示され、クリックで開けます。

```markdown
# 文体プロファイル

## 文とリズム
- 一文は短く、40字を超えることはまれ。
- 段落は具体的な場面から始め、それから要点を書く。

## 使わない
- 感嘆符は使わない。「突然」は使わない。
```

形容詞より、確かめられる具体的な項目のほうが効きます。「簡潔」ではなく「一文は短く、40字を超えることはまれ」と書きましょう。分量は1〜2ページまでに。使われるのは最初の6,000文字だけです。設定の**補完のトーン**も同時に適用されます。文体プロファイルで書きぶりを説明済みなら、「文書に合わせる」のままにしておきましょう。

### ライブラリ

**ライブラリには、一貫させたい設定を置きます。** 人物・場所・用語ごとに1つのMarkdownファイルで、`.levis/library/` に入ります。プロジェクトメニューの **ライブラリに項目を追加…** で名前を入力すると、新しい項目が開きます。**ライブラリ**チップに項目の数が表示されます。

```markdown
---
name: 林晩
aliases: [晩ちゃん, 林先生]
include: detected
---

主人公、32歳、港町の中学校で国語を教えている。
左利き。兄のことは決して話さない。
```

項目を自分で添付する必要はありません。`include: detected`（既定）の項目は、名前か別名が出てきたときに自動的にLevis AIへ渡されます。会話ではあなたのメッセージと文書、補完ではカーソル付近のテキストが対象です。`always` は毎回のリクエストに含まれ、`never` は決して含まれません。言及されない項目はコストにならないので、ライブラリはプロジェクトに合わせていくらでも育てられます。

### 執筆の指示（agent.md）

**執筆の指示は、毎回の会話に添えられる常設のルールです。** このプロジェクトが何なのか、どの言語で返信するか、表記や用語、Levis AIが常に守ること・決してしないことを書きます。`agent.md` というファイルに書き、2つの階層があります：

- **グローバル**（すべての文書）：**設定 > Levis AI > 執筆の指示（agent.md）> agent.mdを編集**。
- **プロジェクト**（1つのプロジェクトの文書だけ）：`.levis/agent.md`。プロジェクトメニューの **このプロジェクトの執筆の指示を編集** で開きます。

どちらもタブで開き、冒頭にコメントで短い説明が入っています。両方あるときはLevis AIに両方が渡され（先にグローバル、後にプロジェクト）、食い違う点はプロジェクトの指示が優先されます。

```markdown
1930年代の上海を舞台にしたミステリー。語り手は林晩（一人称）。
常に日本語で返信する。
人物名は「林晩」と書き、「林晚」とは書かない。
```

執筆の指示が使われるのは会話だけです。補完はこれを読まず、文体プロファイルとライブラリに従います。

### スキル（/名前）

**スキルは、名前の付いた再利用できる指示です。**「推敲」「アウトライン」「引用の確認」などを1つのMarkdownファイルに書きます。先頭に名前と1行の説明、その下に完全な指示を書きます。

```markdown
---
name: polish
description: 選択した段落を、意味を変えずに引き締めて磨き上げる
---

与えられたテキストを一文ずつ磨き上げる：冗長な語を削り、
長い文を短く分割し、元の意味とトーンは変えない。
磨き上げた後のテキストのみを出力する。
```

スキルの使い方は2つあります：

1. **呼び出す**：対話の入力欄に `/` と入力してメニューから選ぶか、名前に続けて依頼を書きます（例：`/polish この段落も見て`）。
2. **ただ頼む**（ツール呼び出しに対応したプロバイダーのみ）：Levis AIは各スキルの名前と説明を把握しており、依頼がいずれかに合うと、自分で完全な指示を読み込んで従います。

スキルも執筆の指示と同じ2つの階層に置けます。グローバルのスキルはグローバル設定フォルダーの `skills/` に（**設定 > Levis AI > スキル > スキルをインポート…** でスキルファイルがそこへコピーされます）、プロジェクトのスキルは `.levis/skills/` に置きます（隠しフォルダーです。macOSのFinderでは <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> で表示できます）。同じ名前のスキルがあるときは、プロジェクトのものがグローバルのものに代わって使われます。

### グローバル設定フォルダー

**グローバル設定フォルダーには、すべての文書に適用されるものを置きます。** グローバルの `agent.md` とグローバルのスキルです。どのプロジェクトにも属さないアプリ自身のフォルダーで、**設定 > Levis AI > グローバル設定フォルダー > フォルダーを開く** で開けます。

```
agent/                ← グローバル設定フォルダー
├── agent.md          ← グローバルの執筆の指示
└── skills/
    └── outline.md    ← グローバルのスキル
```

文体プロファイルとライブラリにはグローバル版がありません。どちらも1つの作品を説明するものなので、プロジェクトに属します。

### いつ何が使われるか

| | 会話 | 補完 | 文法チェック |
| --- | :---: | :---: | :---: |
| プロジェクトのファイル（読み込み・検索・`@`） | ✓ | | |
| 文体プロファイル | ✓ | ✓ | |
| 言及されたライブラリの項目 | ✓ | ✓ | |
| 執筆の指示 | ✓ | | |
| スキル | ✓ | | |
| 補完のトーン（設定） | | ✓ | |

- **グローバルが先、プロジェクトが後。** 両方の執筆の指示が送られ、プロジェクトの指示が後に来て、食い違う点では優先されます。同じ名前のスキルは、プロジェクトのものが使われます。
- **プロジェクトフォルダーは常に1つ。** 有効なのはその `.levis/` だけです。プロジェクトフォルダーを選んだ場合、文書の隣にある `.levis/` は読まれません。
- **再起動は不要。** これらのファイルを編集すると、次のリクエストから新しい内容が使われます（補完には10秒ほどで反映されます）。

### 何をどこに書くか

- 文章がどう読めるべきか → **文体プロファイル**
- 誰が誰で、何が何か → **ライブラリ**
- 会話でLevis AIが知っておくべきこと、常に守ること → **執筆の指示**
- 何度も頼む同じ種類の作業 → **スキル**
- メモ、資料、前の章 → **プロジェクトフォルダー**の普通のファイル（必要なときにLevis AIが自分で読みます）

## プライバシーについて

文書の内容、添付・@メンションしたファイル、執筆の指示、文体プロファイル、言及されたライブラリの項目、Levis AIが読み込んだプロジェクト内のファイルは、選択したプロバイダーへリクエストとともに送信されます。**サンプルから文体を学習** では選んだサンプルが送信されます。ウェブ検索はそのプロバイダーのサーバー側で実行されます。不要な場合は設定で該当機能をオフにしてください。
