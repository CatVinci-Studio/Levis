# 共用寫作規則的提示語（src-tauri/src/ai/rules/messages.rs）。
shared.nfc.invisible = 不可見字元：請刪除。
shared.nfc.compose = 分解形式的附加符號：請改用合成字元。
shared.space-before-punct = 此標點前不應有空格。
shared.double-space = 詞之間有兩個空格：保留一個即可。
shared.doubled-word = 詞語重複：「{0}」連續出現了兩次。
shared.residue = 內文殘留了聊天機器人的套話或預留位置。
shared.library-name = 可能寫錯了資料庫中的名稱「{0}」。
shared.heading-structure.skip = 標題跳級：{1} 級標題後直接出現了 {0} 級標題。
shared.heading-structure.depth = 標題超過三級：建議精簡層級。
shared.image-alt.empty = 圖片缺少替代文字：除非純屬裝飾，請描述圖片內容。
shared.image-alt.long = 替代文字超過 155 個字元：請寫短一些，細節放到內文裡。
shared.image-alt.redundant = 替代文字不必以「圖片：」或「圖像：」開頭。
