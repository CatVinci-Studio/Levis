# 공통 표기 규칙 메시지 (src-tauri/src/ai/rules/messages.rs).
shared.nfc.invisible = 보이지 않는 문자가 있습니다. 지워 주세요.
shared.nfc.compose = 분해된 결합 문자입니다. 완성형 문자를 쓰세요.
shared.space-before-punct = 이 문장 부호 앞에는 띄어 쓰지 않습니다.
shared.double-space = 단어 사이에 공백이 두 칸입니다. 한 칸만 두세요.
shared.doubled-word = 단어 반복: ‘{0}’이(가) 연달아 두 번 나옵니다.
shared.residue = 챗봇의 상투적인 문구나 자리 표시자가 본문에 남아 있습니다.
shared.library-name = 라이브러리 이름 ‘{0}’을(를) 잘못 쓴 것 같습니다.
shared.heading-structure.skip = 제목 수준을 건너뛰었습니다: {1}수준 다음에 {0}수준이 옵니다.
shared.heading-structure.depth = 제목이 세 단계를 넘습니다. 구조를 단순하게 하는 것을 고려해 보세요.
shared.image-alt.empty = 이미지에 대체 텍스트가 없습니다. 장식용이 아니라면 내용을 설명해 주세요.
shared.image-alt.long = 대체 텍스트가 155자를 넘습니다. 짧게 줄이고 자세한 내용은 본문에 쓰세요.
shared.image-alt.redundant = 대체 텍스트를 ‘이미지:’나 ‘사진:’으로 시작할 필요는 없습니다.
