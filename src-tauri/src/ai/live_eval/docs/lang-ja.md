# 週末読書クラブ：初年度報告

市立図書館は、放課後や休日により多くの中高生に来てもらうため、1月に週末読書クラブを始めました。

## 方法

1月から12月までの丸一年間を通して、図書館の職員は毎回の活動の出席状況をひとつ残らず丁寧に記録し、さらにそれに加えて、参加者自身がクラブやその運営方法について実際にどのように考えているのかを知るために、毎月の終わりに短い紙のアンケートを配布しました。

## 結果

登録参加者は1月の120人から12月には310人に増えました。最も多かった不満は、図書館が日曜日の午後4時に閉館するため、日曜日の活動が途中で終わってしまうことでした。

来年は毎月の作家訪問を追加する予定です。
