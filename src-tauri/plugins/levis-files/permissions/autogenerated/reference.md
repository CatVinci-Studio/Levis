## Default Permission

Everything Levis's iOS document access needs.

#### This default permission set includes the following:

- `allow-pick-document`
- `allow-pick-folder`
- `allow-read-text`
- `allow-write-text`
- `allow-list-folder`
- `allow-remembered`
- `allow-begin-access`
