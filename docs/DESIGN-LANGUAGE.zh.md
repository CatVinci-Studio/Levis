# Levis 界面规范

界面采用中性色底、轻边框和单一强调色。布局与操作规则保持一致，配色可以随主题变化。

## 统一规则

- `src/ui/design-system.css` 定义界面变量、焦点、控件高度和减少动画设置。`src/App.css` 提供默认明暗配色。
- 圆角分为 4、6、10、14 px：紧凑元素（菜单项、行内标记）、控件与卡片、浮层、弹窗；标签和单行提示用胶囊形（`--radius-pill`）。只用变量，不写具体数值。普通内容分组不使用阴影；阴影仅用于浮层和弹窗。
- 常规表单控件最小高度为 32 px；面板、工具条和提示条里的紧凑按钮为 26 px（`--control-height-sm`）。设置窄于 760 px 时使用顶部导航，内容区域独立滚动。
- 按钮的尺寸、圆角和悬停、按下、禁用状态只在 `design-system.css` 定义一次，组件样式只写布局和文字颜色。主操作使用实色按钮（每组一个），次要操作使用轻边框按钮，再次一级用文字按钮。同一件事在同一处只出现一个按钮，例如一处修改只有一组采纳/拒绝。
- 界面字号只用四档：11、12、13、14 px（`--text-xs/sm/md/lg`）；更大的只用于标题，更小的只用于角标。正文排版另有一套，不受影响。
- 图标按钮：头部、行内和工具条里为 24 px，无边框；输入栏工具条里带边框，与 26 px 的下拉框和发送按钮等高。下拉框统一用自绘箭头，分常规和紧凑两档。
- 菜单（应用菜单、右键菜单、项目栏菜单、快速提问的下拉菜单）共用面板内边距、菜单项尺寸、悬停色和分隔线。
- 弹出菜单和浮层统一用 `useCloseOnOutsideClick`：点外面或按 Esc 关闭，只在打开时监听。文字输入框的焦点框画在内侧，不压到相邻控件。
- 文字、次要文字、强调色、危险和成功状态各有独立变量。
- 设置、侧栏、菜单、教程、AI 面板和弹窗使用界面变量。原生窗口按钮遵守平台交互约定。

## 主题规则

内置主题只调整正文。默认、纸张、石板、森林、羊皮纸均检查浅色和深色；系统深色与显式深色使用相同变量。正文、链接和次要文字在正文及代码背景上的对比度由测试检查。

导入主题会同步全局配色。`src/utils/theme-chrome.ts` 在独立文档中读取主题背景、文字与链接颜色，再生成界面配色和缺失的编辑器变量。按钮、状态提示和选中项会校正对比度。切回内置主题时移除派生样式，迟到的主题读取结果不会覆盖新选择。

主题原有 CSS 保留。只包含一种配色的主题保持该配色；不会强行反转成深色。远程 `@import`、图片背景、依赖特定 Typora DOM 的布局和任意全局 CSS 不属于完整兼容承诺，需要按实际主题复核。

## 本次验收

- 验证暖色与深色导入样式在设置界面的全局配色。
- 验证 520×620 小窗口设置与教程、键盘焦点和切回默认主题。
- 自动检查主题配色对比度、深色变量一致性、导入清理与加载竞态。

浏览器检查不替代各平台原生窗口、输入法及安装升级验收。
