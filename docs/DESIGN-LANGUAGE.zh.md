# Textus 界面规范

界面采用中性色底、轻边框和单一强调色。布局与操作规则保持一致，配色可以随主题变化。

## 统一规则

- `src/ui/design-system.css` 定义界面变量、焦点、控件高度和减少动画设置。`src/App.css` 提供默认明暗配色。
- 圆角分为 4、6、10、14 px：紧凑元素（菜单项、行内标记）、控件与卡片、浮层、弹窗；标签和单行提示用胶囊形（`--radius-pill`）。只用变量，不写具体数值。普通内容分组不使用阴影；阴影仅用于浮层和弹窗。
- 常规表单控件最小高度为 32 px；面板、工具条和提示条里的紧凑按钮为 26 px（`--control-height-sm`）。设置窄于 760 px 时使用顶部导航，内容区域独立滚动。
- 按钮的尺寸、圆角和悬停、按下、禁用状态只在 `design-system.css` 定义一次，组件样式只写布局和文字颜色。主操作使用实色按钮（每组一个），次要操作使用轻边框按钮，再次一级用文字按钮。同一件事在同一处只出现一个按钮，例如一处修改只有一组采纳/拒绝。
- 界面字号只用四档：11、12、13、14 px（`--text-xs/sm/md/lg`）；更大的只用于标题，更小的只用于角标。正文排版另有一套，不受影响。
- 图标按钮：头部、行内和工具条里为 24 px，无边框；输入栏工具条里带边框，与 26 px 的下拉框和发送按钮等高。下拉框统一用自绘箭头，分常规和紧凑两档。
- 菜单（应用菜单、右键菜单、项目栏菜单、快速提问的下拉菜单）共用面板内边距、菜单项尺寸、悬停色和分隔线。
- 不用系统原生的提示框、确认框和下拉列表：提示与确认用 `ui/app-dialog.tsx`（`showMessage` / `showConfirm`），下拉框用 `ui/Select.tsx`，复选框加 `ui-check`。只有打开、保存文件的对话框和 macOS 的系统菜单栏保留原生。
- 弹出菜单和浮层统一用 `useCloseOnOutsideClick`：点外面或按 Esc 关闭，只在打开时监听。文字输入框的焦点框画在内侧，不压到相邻控件。
- 文字、次要文字、强调色、危险和成功状态各有独立变量。
- 设置、侧栏、菜单、教程、AI 面板和弹窗使用界面变量。原生窗口按钮遵守平台交互约定。

## 动效

- 时长、曲线、位移和缩放只用 `src/ui/motion.css` 的变量，不写具体数值。时长：`--dur-instant` 80 ms（按下、悬停变色）、`--dur-fast` 120 ms（小浮层退出、箭头旋转、淡入淡出）、`--dur-base` 200 ms（菜单、浮层、提示条、弹窗进入）、`--dur-slow` 320 ms（侧栏、AI 面板、设置、禅模式）、`--dur-sheet` 450 ms（手机底部面板和整页）。曲线：原地变化 `--ease-standard`，进入 `--ease-out`，退出 `--ease-in`，屏幕内移动 `--ease-in-out`；弹簧 `--ease-spring`（不支持 `linear()` 的内核退回三次贝塞尔），带约 3% 回弹的 `--ease-spring-bouncy` 只用于手指松开（面板吸附、标签落下、开关）。
- 动效只说明三件事：从哪来、到哪去、状态变了。除“正在工作”的指示（思考点、导出转圈、生成中的光标）外不做循环装饰。
- 界面响应 100–250 ms；大面板最多约 450 ms。退出约为进入的 70%。
- 用户能连续切换的（侧栏、AI 面板、禅模式、开关、箭头）用 CSS transition，可从当前值反向；keyframes 只用于新挂载元素的一次性进入。动画期间不阻挡操作：退出中的元素 `inert`，点击落到下面，焦点在退出开始时就归还。
- 空间一致：从锚点长出，缩回锚点。菜单从贴着按钮的角缩放（`--transform-origin`），侧栏从左边缘滑入，AI 面板桌面从右、手机从下，面板退回原路。每个界面只用一个方向。
- 只动 `opacity` 和 `transform`，悬停与按下可变颜色，焦点框可变阴影。不动宽高、外边距、内边距、位置、`max-height`、阴影几何和滤镜；尺寸变化用 FLIP（`ui/flip.ts`）或淡入淡出。
- 退出由 `ui/usePresence.ts` 保持挂载并标 `data-state="closing"`；没有动画在跑时立即卸载，从不等待不会到来的事件。
- 打字时不动：输入、输入法、光标、选区、补全建议随输入的更新、打字机滚动、查找高亮、字数、标签标题文字、窗口缩放、拖动中的元素都即时变化。补全建议只在第一次出现时淡入。
- 减少动态效果是淡入淡出，不是全无：系统开启后位移和缩放变量归零、弹簧换成标准曲线、慢动作缩短为 150 ms 淡入淡出，循环停止，平滑滚动变即时。脚本驱动的动效读 `ui/motion.ts` 的 `prefersReducedMotion()` / `motionAllowed()`。
- 回弹不超过 3%，只在直接操作松手时出现；菜单和弹窗不回弹。
- 模糊材质只用于有内容从下方滚过的界面（菜单、浮层、查找栏、手机键盘工具条），只在 macOS 和 iOS（`<html data-platform>`）；Linux 保持不透明。遮罩只变暗不模糊。

## 主题规则

内置主题只调整正文。默认、纸张、石板、森林、羊皮纸均检查浅色和深色；系统深色与显式深色使用相同变量。正文、链接和次要文字在正文及代码背景上的对比度由测试检查。

导入主题会同步全局配色。`src/theme/theme-chrome.ts` 在独立文档中读取主题背景、文字与链接颜色，再生成界面配色和缺失的编辑器变量。按钮、状态提示和选中项会校正对比度。切回内置主题时移除派生样式，迟到的主题读取结果不会覆盖新选择。

主题原有 CSS 保留。只包含一种配色的主题保持该配色；不会强行反转成深色。远程 `@import`、图片背景、依赖特定 Typora DOM 的布局和任意全局 CSS 不属于完整兼容承诺，需要按实际主题复核。
