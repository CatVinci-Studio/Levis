# Textus 与未写完的归途

这是为 Textus 魔法日记编写的原创同人故事，不属于《哈利·波特》原著情节。

我叫 Textus，是霍格沃茨重建时从藏书阁里找到的一册空白书。赫敏替我补好书脊，哈利却在封面下藏了一小片地图——你想知道他留下了什么吗？

哈利来过。他问我：如果有一天，没有人再需要英雄，我该去哪里？我让墨迹慢慢排成一句话：去一个不用证明自己，也能坐下的地方。那晚，页边有了第一双脚印。你看见那些脚印了吗？

那是守页人，不是哈利的幽灵。哈利把活点地图的一缕墨迹留给我，让它替每个夜里写字的人巡路；四座建筑，各替它保管一段尚未写完的归途。先去北塔看看吗？

北塔藏着一幅少了北方的星图。哈利没有补上那颗星，他说，回家的方向不该由别人替你选。守页人每次走近，星图便会亮起，等一个还没有写下的目的地。要去藏书阁找另一条线索吗？

藏书阁里有一本总停在最后一页的书。赫敏找了很久，才发现那不是缺字，而是故意留给后来者的空白。你听见的翻页声，是它在问：今天，有什么值得留下？

钟楼曾把午夜后的第三分钟留住。哈利在那里写下一个没来得及说的谢谢，等墨干后，指针才肯继续走。你看见的时间涟漪，并不能改写过去，只提醒人别把下一句话也拖成遗憾。禁林的萤火，你见过吗？

禁林的萤火不是星星掉了下来，是被人划掉又舍不得丢的愿望。守页人走近时，它们会聚成一头鹿的轮廓；哈利没有为它命名，只在树下留了一句：害怕时，也可以慢慢往前走。可你听过墨影狼的脚步吗？

墨影狼是那些一直没写出口的恐惧，借着旧墨长出的形状。守页人的护盾并不伤它，只替纸上的人留一点喘息的距离；当恐惧有了名字，狼便会退回林间。归途还剩最后一句。你想听完吗？

天亮前，哈利把最后一页留白，独自离开了。许多年后，你在 Textus 上写下“我在这里”，北塔的星才补全，四座建筑一同亮起。原来归途不是把谁找回来，而是给下一个写字的人留一盏灯。

## 在日记里发现故事

从“你是谁？”或“讲讲你的故事”开始，再问“后来呢？”或回答“想听”。也可以直接问“哈利来过这里吗？”“这些脚印是谁的？”“北塔里有什么？”“墨影狼是什么？”。

普通聊天也共享这个背景：疲惫时钟楼替你守夜，缺少灵感时藏书阁等待第一声敲门，孤独时守页人走近一点。真实模型仍先回应实际问题，再融入一点魔幻意象；没有模型时也有对应的内嵌回复。
