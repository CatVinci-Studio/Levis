## 更新内容

- 正文宽度可在设置中选择：默认「自适应」会在宽屏上加宽正文，字号随之略微放大；也可选「标准」或「铺满」。
- 缩放时以鼠标位置为锚点，正文不再上下跳动。
- 图片后不再多出空行；图片右侧新增拖动手柄，可直接调整宽度。
- PDF 导出：三个平台都直接生成 PDF 文件，不再经过系统打印对话框。页面边缘不再裁切文字、公式和表格；macOS 和 Windows 上深色及带底色的主题也能铺满整页，没有白边。导出的 PDF 和 HTML 中本地图片可以正常显示，标题前的 # 和代码块的语言选择框不再出现在导出结果中。
- AI 对话面板：明确了展开与关闭的规则。纯问答回复自动展开，修改文档的回复保持紧凑；快捷键先聚焦输入框，再按一次关闭；Esc 在面板任意位置都可关闭；有未处理的修改时，关闭前会先确认。对话弹出到独立窗口后，快捷键会切换到该窗口。
- AI 回复支持完整的 Markdown 显示，包括数学公式、表格、标题和任务列表；面板在宽屏上限制宽度并居中。
- OpenAI 模型更新为 GPT-6 系列（gpt-6-astra、gpt-6.1-sol、gpt-6-luna）；自动补全和语法检查使用较低推理强度，响应更快。
- 统一正文各类块的间距与圆角；代码块的语言选择移到右上角，行距恢复正常；Mermaid 图表在原位置修改后会及时刷新，甘特图文字恢复可读。
- 公式较多的长文档中，输入和光标移动明显更流畅。
- 切换源码模式和编辑模式时保留光标位置和滚动位置。
- 导入的主题通过 `#write` 设置的 `max-width` 现在会生效；新增「自定义 CSS」，可在当前主题上做首行缩进、行距、字体等局部调整，并可将当前主题导出为 CSS 文件。
- Linux：窗口改为与 Windows 相同的一体化标题栏，菜单跟随界面语言，单窗口时标题不再单独占一行，F11 可切换全屏。

macOS、Windows 和 Linux 安装包由发布流程构建。Linux 上导出的 PDF 使用普通页边距，深色主题的上下边距可能为白色。
