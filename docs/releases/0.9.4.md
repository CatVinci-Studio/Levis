## 更新内容

### 编辑

- 回车的行为在各类块中统一：
  - 表格中按回车移到下一行，在最后一行按回车新增一行，新行留空时再按一次回车离开表格；Ctrl/⌘+回车随时离开。
  - 输入 `| 姓名 | 年龄 |` 后按回车即可生成表格。
  - 在代码块和公式块末尾的空行上按回车即可离开，不再限于文档末尾。
  - 引用块也可以用 Ctrl/⌘+回车离开。
- 表格右键菜单的"选中整行""选中整列"会高亮选中的单元格；表格操作作用于右键点击的单元格。

### 主题

- 导出的主题 CSS 包含二级标题下划线、三级标题竖线、引用块背景等装饰，编辑后再导入不再丢失。
- 内置主题的表头带有与引用块、代码块相同的背景色。

### 其他

- Milkdown 升级到 7.22.3。

macOS、Windows 和 Linux 安装包由发布流程构建。
