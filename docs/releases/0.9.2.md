## 更新内容

### 问题修复

- 修复从帮助菜单打开 Markdown 指南或 AI 功能指南时，会一次出现多个相同标签的问题。
- 切换界面语言后，已打开且未修改的指南会随之换成新语言。
- 修复应用菜单中用方向键打开子菜单后，焦点没有进入子菜单的问题。

### 设置

- 精简"打开文档方式""恢复上次的文档"等选项，去掉不必要的说明文字；"自动建议文件名"改为"新文件保存时自动建议文件名"。
- "编辑与外观"中，编辑相关设置放在最前；自定义 CSS 收起为一个可展开的选项。

### 菜单

- 视图菜单重新分组：侧边栏与 AI 面板；源码、分屏、打字机与禅模式；缩放与全屏。

macOS、Windows 和 Linux 安装包由发布流程构建。
