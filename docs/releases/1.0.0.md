## 更新内容

Textus 1.0.0：下一代 Markdown 编辑器。下笔成章，AI 研墨。

### 新名字，新图标

- Levis 更名为 Textus，换上新的羽毛笔图标；AI 助手随之更名为 Textus AI。
- 应用标识改为 `com.catvinci.textus`，与 Levis 互不干扰，可以同时安装。

### 重新设计的 Textus AI

- 修订在正文里逐句取舍：每处改动的原句标在正文中，新句子和 ✓ / ✕ 放在页边，细线连到原句；编辑器底部的审阅条可以逐处跳转、整体采纳或拒绝。最后一句做完决定，修改即生效。窗口较窄或在手机上时，新句子和 ✓ / ✕ 直接显示在正文里。
- 审阅批注贴在原文旁边的页边，悬停时原文和批注一起高亮，可以追问或标记为已处理；没有页边空间时，原文后显示编号，点开查看。
- 语法检查卡片标出问题类型（错别字、语法、标点、写作规范），以“原文 → 改法”显示，按钮直接写着改法和 Alt+Enter；同一段有多个问题时可以逐个切换。
- AI 面板新增“记忆”页：文风档案、资料库（标出本文用到的条目）、写作要求和技能集中在一处，点开即可编辑。
- 面板顶部合并为一行；修订和批注卡片更精简。
- 手机上，收到修订后 AI 面板自动收起，正文滚到第一处修改，底部的审阅条可随时回到对话；批注和语法建议从底部弹出卡片。

### 全新的界面风格

- 按钮统一为圆角胶囊样式，主按钮使用当前主题的颜色：内置主题和导入的 Typora 主题都会让 AI 面板、审阅条、卡片一起变化，深色主题下自动反转。

### 改进与修复

- 界面新增繁体中文、日语、韩语、西班牙语、法语、德语、俄语和葡萄牙语，共 10 种语言；语法检查的解释跟随界面语言。
- 导出：PDF 四周留出约 20 毫米边距；脚注、高亮、图片宽度、提示框和 Mermaid 图表在 Word、ODT、EPUB、RTF 中按页面所见导出；HTML 导出保持当前的深浅色；公式、图表和提示框不再被分页截断。
- 保存：Windows 换行和 BOM 原样保留；只读文件会提示无法保存，不再静默失败；符号链接写回它指向的文件，文件权限保持不变。
- 撤销已采纳的 AI 修改后，修改提议回到待定，可以重新采纳或拒绝。
- 三击选中整段后让 AI 改写，采纳时不再把这一段和下一段并在一起。
- 表格里续写：建议合并为一行，不会拆坏表格；右键表格外的段落时显示段落的菜单；从右键菜单触发续写后可以直接按 Tab 采纳。
- AI 面板里选过的模式在新对话和独立窗口里沿用；接受续写后不再立即请求下一条建议。
- 打开 AI 面板时，正文的滚动条只在滚动时显示。
- 新建窗口的快捷键统一为 ⌘⇧N / Ctrl+Shift+N。

### 从 Levis 导入

- 首次启动时，如果这台电脑上有 Levis 的数据，Textus 会提示导入：设置、AI 对话和剪贴板历史、主题、写作要求、技能、最近打开的文件、打开的文档和未保存的草稿。API 密钥和 ChatGPT、Claude 的登录状态会单独询问。
- 导入只复制，不改动 Levis 里的任何内容。之后也可以在 设置 → 通用 → 从 Levis 导入 中再次导入。
- 项目文件夹改用 `.textus/`。Levis 留下的 `.levis/` 仍可读取；需要修改其中的文件时，Textus 会先复制到 `.textus/`，原文件保持不变。

### 安装与更新

- Homebrew：`brew install --cask catvinci-studio/tap/textus`。原来通过 Homebrew 安装 Levis 的用户，`brew upgrade` 会自动换成 Textus。
- Arch Linux：`textus-bin` 取代 `levis-bin`，`sudo pacman -Syu` 会自动替换。
- 自动更新使用新的更新清单，Textus 与 Levis 的更新互不影响。

macOS、Windows 和 Linux 安装包由发布流程构建。
