## 更新内容

0.9 是一次以写作为中心的 AI 更新：AI 读得懂你的项目和文风，改动逐句可选，编辑器新增分屏、打字机和禅模式。

### AI 面板

- AI 对话默认显示在编辑器右侧，随文档切换；窗口顶栏的对话按钮或 Ctrl/⌘+Shift+L 开关，仍可展开为独立窗口。
- 快速提问（选中文字后弹出）默认进入“编辑”，可一键展开到右侧面板继续。
- 每条修改建议都附带理由；一段改动可以逐句勾选，只采纳需要的部分（同一个“采纳”按钮会显示“采纳 1/2 处”）。
- 修改卡片和快速提问的界面重新整理：一处修改只有一组采纳/拒绝，不常用的按钮只在需要时出现。
- AI 可以在光标处插入内容，也可以只留批注而不改原文，批注可在文档中定位。
- 错误提示更清楚：未配置、密钥无效、请求过于频繁、模型不可用、服务端或网络问题等分别给出原因和处理办法。

### 项目与写作资料

- 保存过的文档所在的文件夹即为项目，AI 可以浏览、阅读和搜索其中的文本文件；在输入框中用 @ 引用文件。主目录、根目录等过大的文件夹不会被当作项目。
- `.levis/style.md`：文风档案。可从你挑选的范文中“学习文风”自动生成，续写和修改都会贴近你的写法。
- `.levis/library/`：资料库。人物、术语、设定等条目按名称和别名自动匹配，相关条目会随请求一起提供给 AI。

### 续写与语法

- 续写更贴合上下文：参考标题、所在章节和文风档案，避免常见的 AI 套话。
- Ctrl/⌘+→ 逐词采纳续写，Alt+[ / Alt+] 切换候选，Esc 取消。
- 语法检查：光标停在问题上即显示建议，Alt+Enter 直接采纳，可选择忽略。

### 编辑器

- 分屏模式：左侧源码、右侧实时预览，滚动同步（Ctrl/⌘+Shift+E）。
- 打字机模式：正在输入的一行始终保持在窗口中间（设置 → 编辑与外观）。
- 禅模式：隐藏界面、全屏，只突出当前段落（Ctrl/⌘+Shift+J，Esc 退出）。
- 窗口标题显示当前文档名，任务栏和窗口切换时更容易区分。
- 按钮、圆角和弹出菜单的样式与交互统一：同类按钮大小一致，菜单都可以点外面或按 Esc 关闭。
- 欢迎页显示正式的应用图标。
- 首次使用的教程新增侧边栏介绍。

### 模型

- 内置模型列表只保留各服务的默认模型（Anthropic：Agent 使用 Claude Sonnet 5.5，续写使用 Claude Haiku 5.5），模型信息每周从 models.dev 同步。
- 可在设置中拉取服务商当前提供的全部模型自行选择。
- Anthropic 请求启用提示缓存，长对话更快、更省。

### Windows 与 Linux

- Windows、Linux 上从文件管理器打开文件时，会交给已经打开的 Levis，不再另起一个进程。
- 关闭编辑窗口时，它的独立对话窗口一起关闭。
- 文件对话框作为编辑窗口的子窗口显示；保存时自动补全 .md 扩展名。
- Linux 上改进 NVIDIA 显卡的显示兼容性。
- 登录凭据文件仅当前用户可读。

### 问题修复

- 修复 AI 修改卡片中删除行数显示为乱码（`−`）的问题。
- 修复滚动时弹出层停留在原位、右键菜单误触发等问题。
- 修复 AI 面板打开时（以及 Windows 上始终）按 Esc 无法关闭查找栏等问题。
- 修复快速提问在收到修改后跳到文档末尾、看不到采纳按钮的问题。
- 修复分屏预览中的代码块没有背景和边框的问题。

macOS、Windows 和 Linux 安装包由发布流程构建。
