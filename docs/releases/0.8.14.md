## 更新内容

### 问题修复

- 修复保存时可能丢失内容的问题：连续输入一大段后立即保存，最后输入的部分可能没有写入文件；保存过程中窗口焦点变化时，未写入的内容还可能被丢弃。关闭窗口、切换源码模式、拖动标签页时同样会先取得编辑器中的最新内容。
- 修复在数字列表中按回车后，用输入法输入中文时出现多余空行、文字重复或乱码的问题。
- 修复 Linux 上输入法选词后需要按两次回车才能换行的问题。
- 修复 Linux 上中文无法加粗的问题。
- 修复保存时紧凑的无序列表被改成每项之间空一行的问题。
- 代码块的语言标签不再遮挡第一行代码 ([#16](https://github.com/CatVinci-Studio/Levis/issues/16))。
- 列数较多的表格不再超出正文范围，改为在正文宽度内横向滚动 ([#15](https://github.com/CatVinci-Studio/Levis/issues/15))。

### 主题

- 导入的 Typora 主题现在可以完整控制引用块、表格、代码块等样式，不再被 Levis 自带的样式覆盖；使用导入主题时，Levis 自带的标题装饰和引用块底色会自动关闭，效果更接近 Typora ([#13](https://github.com/CatVinci-Studio/Levis/issues/13))。

### Linux 窗口

- 窗口四周新增细边框，边缘和四角可以直接拖动调整大小，鼠标移到边缘即显示缩放光标 ([#11](https://github.com/CatVinci-Studio/Levis/issues/11))。
- 记住上次关闭时的窗口大小 ([#11](https://github.com/CatVinci-Studio/Levis/issues/11))。
- 在 Wayland（niri 等平铺式窗口管理器）下，AI 浮动对话窗口会作为编辑窗口的子窗口浮动显示，而不是占用新的一列。

### 性能

- 编辑时不再重新渲染所有已打开的标签页；移动光标时不再反复扫描整篇文档，长文档编辑更流畅。

macOS、Windows 和 Linux 安装包由发布流程构建。
