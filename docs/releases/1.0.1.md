## 更新内容

Textus 1.0.1：修复 1.0.0 发布后大家反馈的问题。

### 输入法与列表

- 用中文输入法在新建的列表或待办项里打字，不再多出空项，也不会把拼音拆开；待办的勾选状态保持不变。表格单元格里同样修复。
- 新写法直接生成待办：`- 【】`、`-【】`、`- []`、`-[]`，在列表项里输入 `【】` 也可以；写成 `【x】` 或 `[x]` 即为已完成。输入 `- [ ] ` 时，结尾的空格不会留在待办开头。
- 在表格最后一行按回车，新的一行从第一个单元格开始。
- 鼠标移到表格的列分隔线上时，表格高度不再变化。

### 粘贴

- 粘贴截图会保存到文档旁的 `assets/` 目录并插入相对路径，重新打开文档后图片仍在（未保存的新文档会在第一次保存时一起移过去）。
- 从文件管理器复制图片文件后粘贴，插入的是图片而不是文件链接。
- 粘贴网址生成可点击的链接，保存为 `[网址](网址)`；文字为空的链接 `[](网址)` 显示网址本身，保存时保持原样。

### 导出 PDF

- 修复 Linux 上非英文系统导出 PDF 一直转圈、无法完成的问题。
- 导出失败时显示错误信息，不再被进度提示挡住。
- Linux 上带底色的主题导出 PDF，最后一页整页都有底色。

### 标题与源码模式

- 五级、六级标题与正文同样大小，不再比正文小；四级标题略大于正文，六级标题颜色稍淡。
- 源码模式的文字与正文同样大小，编辑时文字保持清晰。

### 其他改进

- 按 Esc 关闭右键菜单时，灰色的续写建议保留。
- 新建资料库条目后，AI 面板停留在“记忆”页。
- 撤销已采纳的修改后，卡片上的改动数正确显示增删两部分。
- 窄窗口和手机上，批注编号与 AI 对话中的批注卡片一一对应。
- 文档里的 HTML 注释显示为淡色的提示文字，光标移入后可以编辑原文。
- macOS 26：窗口按钮与标题对齐，空文档不再出现多余的滚动。
- 鼠标在表格上滚动时，滚动的是整篇文档。
- 模式选择框的读屏名称改为“模式”。

macOS、Windows 和 Linux 安装包由发布流程构建。
