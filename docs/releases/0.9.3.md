## 更新内容

### 问题修复

- 修复视图菜单中"分屏"和"禅模式"点击后没有反应的问题（对应的菜单快捷键同样恢复）。
- 修复菜单操作偶尔被执行多次的问题，例如"新建文件"一次打开多个标签。
- 在引用块中，于行首按退格可以把这一行移出引用。
- 切换界面语言后，空文档的提示文字随之更新。
- 修复输入框最小高度失效的问题。

### 界面

- Windows 和 Linux 的应用菜单中，侧边栏、源码模式、打字机模式、禅模式等开关项显示勾选状态。
- 右键菜单中的"删除"等危险操作以红色显示。
- 窗口较窄时，设置顶部的分类标签改为一行横向滑动，不再换行。

macOS、Windows 和 Linux 安装包由发布流程构建。
