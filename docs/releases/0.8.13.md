## 更新内容

- Arch Linux：新增签名的 pacman 软件源 [`[catvinci]`](https://github.com/CatVinci-Studio/arch-repo)，提供 `levis-bin` 包。按 README「安装」一节配置一次后，`sudo pacman -Syu` 会自动升级 Levis。
- 通过软件包管理器安装的 Levis 仍会提示新版本，但不再自行下载安装，而是提示用包管理器更新，避免与 pacman 管理的文件冲突。
- GitHub Release 新增 `Levis_0.8.13_linux_x86_64.tar.gz`，供 Linux 软件包使用。

macOS、Windows 和 Linux 安装包由发布流程构建。
