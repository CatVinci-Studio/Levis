## 更新内容

Textus 1.0.3：复制、粘贴和登录的改进。

### 复制与粘贴

- 复制到微信等只接收纯文本的 App 时，得到的是可读文字：链接写成“文字 (网址)”，不再带 Markdown 符号。粘贴到 Word、邮件或 Textus 时仍然保留格式。需要 Markdown 原文时，可以在“设置 › 编辑与外观 › Markdown › 复制到其他 App 时”里切换。
- 右键菜单的“复制”和快捷键复制的结果一致，同时带格式和纯文本。
- 在链接文字中间粘贴网址，不会再把链接拆开；选中一段文字后粘贴网址，这段文字会变成指向该网址的链接。

### 登录

- 使用 ChatGPT 或 Claude 账号登录时，如果浏览器没有自动打开，设置里会显示登录链接和“复制链接”按钮，在这台电脑的浏览器里打开即可完成登录。

macOS、Windows 和 Linux 安装包由发布流程构建。
