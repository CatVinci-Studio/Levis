## Cmd＋方向键问题的原因与修复范围

这里不是独立的“Mac 模式”开关，而是根据运行平台识别 macOS。

代码中可以直接确认：`escape-trailing-block-plugin.ts` 原先没有过滤修饰键；标题标记和行内格式使用不可编辑的装饰节点，原有代码也已针对普通左箭头和 Cmd＋Backspace 实现了绕过标记的处理，但没有完整的 Cmd＋方向键方案。

新插件在编辑器扩展前部注册，直接计算目标选区，从文档坐标绕过装饰节点，避免依赖标记附近的原生光标行为。定位只改变选区，不插入正文；输入法合成期间和只读编辑器不拦截。

浏览器预览已实测 Cmd＋左右、Cmd＋上、软换行首尾及 Cmd＋Shift＋左选区。旧版本的 macOS 原生 WKWebView 现场未复现，因此“原生标记导致卡住”仍属于依据代码和已有兼容处理得到的判断；完整原生行为应按下方验收矩阵继续验证。

## 状态管理约定

此次把两个容易失控的生命周期补齐：

- 草稿：禁用 → 不调度；启用且有修改 → 等待写入；新输入 → 更新等待内容；达到最长等待 → 发出写入；保存、关闭或卸载 → 取消尚未触发的任务。
- 弹窗：打开 → 聚焦首个控件；Tab / Shift＋Tab → 在弹窗内循环；Escape / 取消 → 关闭并恢复原焦点。快捷键录制是弹窗中的局部状态，Escape 优先结束录制。

取消计时器不等于撤回已经发出的 Rust 写入。跨 IPC 的保存、删除顺序仍需要独立的后端协调，这是后续状态机工作的重点。

## 设置与教程的补充改进

- 设置页增加当前分类标题，切换分类后从顶部开始。模型、代理、图片设置等复杂行可换行，避免窄窗口溢出。
- 设置配色使用独立的界面变量，不再继承正文主题的文字色；系统、浅色、深色的原生控件配色保持一致。
- 外观改为可直接选择的三项单选控件，支持键盘操作；主题导入和删除增加忙碌状态及错误提示。
- 快捷键录制提示重复绑定的动作名称，并拒绝常见的固定应用快捷键。服务选择列表中的 Escape 只关闭列表，不再连带关闭设置。
- 首次语言选择和教程阅读页补齐焦点循环。练习卡不限制正文焦点，可以收起说明；长练习只滚动内容，导航按钮保持可见。
- 教程恢复时校验步骤编号，修复小数编号导致无效步骤的问题；退出后的延迟导航不再改变进度。
- 三种语言的教程都改为直接说明功能、操作和结果。明确教程使用预设回复、无需登录；跳过练习后不再宣称全部技能已完成。
- 中文内置 AI 指南的连接步骤已按当前设置界面重写，并补充 Windows/Linux 快捷键说明。

## 多平台保障的实际范围

原 CI 的前端检查运行在 Linux，Rust 检查仅运行在 macOS；Windows/Linux 原生构建主要发生在发布流程。此次将 Rust 格式检查、Clippy 和测试扩展到 macOS、Windows、Linux 三平台，发布前也增加前端检查与 Rust 测试。

远端 macOS、Windows、Linux 的前端检查、Rust 静态检查与测试均已通过；0.8.11 三平台安装包也已构建并发布。macOS 已通过 Apple 公证，自动更新清单的版本、平台、下载地址与签名字段已核对。原生菜单、输入法、DPI 缩放、安装与升级仍需各平台真机验收，不能据此承诺所有设备和第三方主题都没有问题。
